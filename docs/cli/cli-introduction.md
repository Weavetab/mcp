# CLI Reference

The `weavetab` binary provides server management, secrets handling, diagnostics, and interactive terminal menus.

```bash
weavetab          # Start the MCP server (stdio mode)
weavetab config   # Interactive configuration wizard
weavetab view     # Inspect active configuration
weavetab reset    # Purge profiles, lockfiles, and stale sessions
weavetab help     # Command index
```
